# database Chrome拡張

長町南店の機種別一覧と台グラフだけをフルページ撮影します。外部サーバーへ画像を送信しません。

## 初回設定

1. Chromeで `chrome://extensions` を開く。
2. 右上の「デベロッパーモード」をオンにする。
3. 「パッケージ化されていない拡張機能を読み込む」を押す。
4. この `chrome_extension` フォルダを選ぶ。
5. 拡張機能メニューから `database` を固定する。

## 操作

対象ページを表示して、Chrome右上のdatabaseアイコンを押すか `Ctrl + Shift + Y` を押します。撮影中はアイコンに数字が表示されます。完了すると `ダウンロード/database` にPNGが保存されます。

databaseアプリを起動した状態なら、新しく保存されたPNGを検出して取り込み画面を開きます。
