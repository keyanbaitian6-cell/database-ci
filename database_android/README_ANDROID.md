# database Android試作

メルヘンワールド長町南店・スーパーメルヘンワールド幸町の1000円46枚スロットを、スクリーンショットから端末内で整理する個人用アプリです。

## できること

- Chromeの共有メニューまたは端末の画像選択から画像を取り込む
- 一覧画像を日本語OCRし、台番号・BIG・REG・総回転数・前日最終スタート・最大持玉を編集して保存する
- 台別グラフを自動検出し、ゼロ線・最高点・最低点・終点をタップで補正する
- 当たり頻度60点、最大持玉20点、終点10点、維持10点で採点。回転数は加点せず縮約に使う（v10）
- 最大持玉は、枚数による点（19,000枚のコンプリート上限で満点）が順位による点を上回ればそちらを使う
- 当日500G以下の台は採点しない（v10）
- 20件未満の比較では暫定点として表示する
- 結果はアナスロ型：翌日候補（仮）・設置機種一覧のあとに全機種を並べ、機種ごとに「データ表示（台番号・G数・BB・RB・確率・最大持玉・推定設定・点数、平均行）」と「グラフ表示」を切り替える
- 過去の記録は日付ごとに機種を1行で並べ、店舗・種別・機種名（ひらがな・半角カナ可）で絞り込む
- CSVは選択した店舗・日付の範囲から「日付・機種名・台番号・採点結果・G数・最大持ち球・B・R・設定情報」の9項目を出力する

画像とデータは端末内に保存し、アプリから外部サービスへ送信しません。対象店舗のページを開くボタンだけがブラウザを起動します。

## 取り込みのコツ

一覧は列見出しを含めて撮影します。グラフはグラフ部分の左右端と赤いゼロ線を含めます。OCR結果は保存前に必ず確認し、台番号や数値を訂正できます。

初回起動時にはPC版の保存済み110件を履歴の初期データとして読み込みます。別端末への移行や復元には、アプリのバックアップ・復元機能を使用してください。

## CSVとバックテスト

共有用CSVは日付と台番号を出力します。店舗名は出力範囲で選択できますがCSV列には含みません。翌日候補の店舗別バックテストには、店舗情報を含むPCデータベースまたはアプリのバックアップJSONを併用してください。バックアップと同じ記録の共有用CSVがある場合は、`database/backtest_candidate_scores.py --json バックアップ.json --csv 共有用.csv` で、一意に照合できた台について翌日の採点結果も比較できます。旧形式の詳細CSVは引き続き入力できます。
