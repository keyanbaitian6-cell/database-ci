# database Android試作

メルヘンワールド長町南店・スーパーメルヘンワールド幸町の1000円46枚スロットを、スクリーンショットから端末内で整理する個人用アプリです。

## できること

- Chromeの共有メニューまたは端末の画像選択から画像を取り込む
- 一覧画像を日本語OCRし、台番号・BIG・REG・総回転数・前日最終スタート・最大持玉を編集して保存する
- 台別グラフを自動検出し、ゼロ線・最高点・最低点・終点をタップで補正する
- 当たり頻度60点、最大持玉20点、終点10点、維持10点で採点。回転数は加点せず縮約に使う（v9）
- 最大持玉は、枚数による点（19,000枚のコンプリート上限で満点）が順位による点を上回ればそちらを使う
- 20件未満の比較では暫定点として表示する
- 結果は機種一覧から選び、台は1台1行の表で見る（前後の機種へボタンで移動）
- 過去の記録は日付ごとに機種を1行で並べ、店舗・種別・機種名（ひらがな・半角カナ可）で絞り込む

画像とデータは端末内に保存し、アプリから外部サービスへ送信しません。対象店舗のページを開くボタンだけがブラウザを起動します。

## 取り込みのコツ

一覧は列見出しを含めて撮影します。グラフはグラフ部分の左右端と赤いゼロ線を含めます。OCR結果は保存前に必ず確認し、台番号や数値を訂正できます。

初回起動時にはPC版の保存済み110件を履歴の初期データとして読み込みます。新しい端末へ移す場合は、将来のバックアップ機能追加まで、元のPC版データを保管してください。
