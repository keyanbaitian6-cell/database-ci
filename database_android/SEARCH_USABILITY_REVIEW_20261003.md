# 機種名・台番号検索の使い勝手改善（2026-10-03）

## 確認した問題と修正

利用者の「作業効率化・利便性の改善」の依頼に対し、共通の一覧から目的の台を探す操作を改善した。作業開始時の正本は `773e9d7cf786b7c727deb4c1b5acba1954589990`。

- 従来の検索は機種名のみで、Android結果画面と閲覧版では6機種以下だと検索欄が出なかった。記録がある一覧では機種数にかかわらず検索できるようにした。
- `123` / `１２３` / `123番台` / `#123` で台番号を完全一致検索できる。数字だけの入力では、従来の「ジャグラー3」などの機種名部分一致も残す。`番台` または `#` を付ければ台番号のみを探す。
- Androidの結果・履歴、メルヘン/P’s CUBEの共通閲覧画面で同じ判定を使用。詳細画面・グラフ・記録日の切替にも検索条件を引き継ぐ。
- 該当なしの案内に機種名・台番号と検索解除の方法を表示する。Androidの結果画面で一部の台だけを表示中は、見えていない台も対象になる機種全体の削除ボタンを表示しない。
- 機種名の正規化結果を1回の検索内で再利用する。バラエティ判定・採点・翌日候補は元の記録全体を基準に計算し、検索では表示対象だけを絞る。
